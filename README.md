InventarioUNISON

Este es un proyecto de inventario que hice en Java para la escuela.  
La idea es tener un sistema sencillo para registrar artículos, editarlos, eliminarlos y llevar control básico.  
Usa SQLite como base de datos y Java Swing para la interfaz.
